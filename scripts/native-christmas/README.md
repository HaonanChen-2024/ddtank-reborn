# A16 partial: original double entrance and local snowman

This module preserves the original double entrance, quantity/MAX/double dialog, scrolling reward rows, experience bar and snowman MovieClip. The real snowfield, original snowpack items, tickets, monsters, PvE and scene-return lifecycle remain unavailable. This is not completion of A16 or all 17 activities.

The frozen local contract is `native-christmas-contract-a.ts` with its unavailable-state, isolated-art and postcommit-synchronization addenda. An unavailable projection may have a completely empty API skeleton or the game's complete disabled 4/20/4 catalog; the module accepts both without enabling actions. The game owns task-snowpack entitlement, activity points, four reward tiers, permanent/cyclic claim keys, UUID receipts and mail in its transaction. The Flash module never writes a socket, wallet, inventory or mailbox. Ordinary and double crafting use one explicit finite request; quantity, MAX, help, cancel and disposal never submit.

The module exports `buildNativeChristmas` / `auditChristmas` and uses four fixed files under `/flash/workshop-native/christmas/`: `WorkshopNativeChristmasBootstrap.swf`, `christmas-original-library.swf`, `christmas-original-art.swf`, `christmas-styles.xml`. Five module callbacks are `workshopChristmasAcceptSnapshot`, `RejectRequest`, `OpenNative`, `CloseNative`, `StatusNative`; page calls are `workshopChristmasRead/Request/Report`. The common bridge owns `workshopOpen/Status/CloseChristmas` and the sole shared 82-ABC library.

Only 12 selected original business owners and the exact bitmap glue enter the library. Original business names/private access and 110 named style definitions are isolated locally; the 11 raw bitmap style records are retained. The cached source XML/art remains byte-identical. The runtime art isolates the two colliding `road.game.resource::ActionMovie` / `ActionMovieEvent` support definitions to `workshop.christmas.art.resource` through exactly three namespace strings; all method bodies, non-support class names and non-ABC tags remain unchanged. Its single dynamic lookup still names the existing `ddt.manager.SoundEffectManager`; the support version text is unchanged. Runtime art is therefore intentionally not byte-identical to the original. Missing `asset.core.btmc011` is explicitly replaced only in the runtime entrance style by cached original `asset.ui.frame.bg2`; its original symbol was not recovered. Local text uses Microsoft YaHei and explicit task/economic labels.

GET/replay only render. A fresh crafted effect with `isUp=false` finishes synchronously; `isUp=true` runs the original 48-frame movie. An owned listener captures frame 47 before the preserved original handler resets to 48, then unlocks. Close removes listeners and stops the clip without another POST. Closing a pending action retains its UUID; late actions cannot reopen a window or restart a movie. The original global keyboard stop is not copied.

None of those runtime or user acceptance checks is implied by an offline candidate. No live installation is performed by these tools.

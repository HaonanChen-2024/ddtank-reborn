## 文档同步与历史恢复

```sh
node scripts/sync-notes.mjs --mirror="Obsidian项目目录"
node scripts/sync-notes.mjs --mirror="Obsidian项目目录" --write
```

默认只检查。`--write`将repo三份短文档和历史归档同步到项目与镜像；素材台账仍以项目为源，仅同步镜像。不同内容的既有历史归档拒绝覆盖；变动短文档先在 `runtime/notes-sync-backups/时间戳` 保存目标原字节；不删除目标额外文件。可用 `--project=项目目录` 指定项目，或以 `WORKSHOP_NOTES_MIRROR` 提供镜像路径。

全文归档在repo `docs/archive/2026-10-17-before-slim`，项目为 `docs/归档/同日期`，镜像为 `归档/同日期`。`snapshot-manifest.json` 保存原位置/字节/SHA，`history-index.json` 保存连续UTF-8半开字节区间。计划原文按原位置复制且核SHA即可恢复；执行记录须按 `append-manifest.json` 的 `restoreOrder` 将 `执行记录.md` 与 `工程整理追加记录.md` 作为原字节顺序拼接，不解码、不补换行，再核 `reconstructed.sha256`，才能恢复安装前完整历史。原两大正文与新增尾部均不重新编码或清理空白；后续新历史另用新日期归档，保留旧版本。
